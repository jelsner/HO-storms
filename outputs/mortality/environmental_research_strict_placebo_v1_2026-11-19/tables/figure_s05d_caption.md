# Figure S5D

Empirical null distributions from 199 strict temporal placebo calendars for the four all-age event periods. Randomized impact dates preserve event year, weekday, season, and ZIP footprint, while ensuring that no placebo window overlaps any observed event window affecting the same ZIPs. Orange lines indicate the frozen primary rate ratios and dashed lines indicate permutation medians. The global standardized maximum-statistic test across all four periods yields p=0.005.
